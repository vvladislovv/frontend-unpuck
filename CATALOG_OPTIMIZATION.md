# Оптимизация каталога товаров

## Реализованные оптимизации

### 1. Пагинация и ленивая загрузка
- **Начальная загрузка**: 30 товаров
- **Подгрузка**: по 10 товаров при скролле
- **Автоматическая подгрузка**: при приближении к концу списка
- **Ручная подгрузка**: кнопка "Загрузить еще товары"

### 2. Кэширование
- **Время жизни кэша**: 5 минут
- **Максимальный размер**: 50 записей
- **Умное кэширование**: избегает дубликатов при подгрузке
- **Очистка кэша**: автоматическая при изменении параметров поиска

### 3. Виртуализация (опционально)
- **Виртуализированный список**: рендерит только видимые элементы
- **Адаптивные колонки**: 1-4 колонки в зависимости от размера экрана
- **Плавный скролл**: с предзагрузкой элементов за пределами видимой области

### 4. Производительность
- **Мемоизация**: `useMemo` и `useCallback` для предотвращения лишних рендеров
- **Оптимизированные запросы**: только необходимые параметры
- **Ленивая загрузка изображений**: через Next.js Image компонент
- **Debounced поиск**: предотвращает лишние запросы при вводе

## Использование

### Базовый каталог (с пагинацией и кэшированием)
```tsx
import { ProductGrid } from '@/components/catalog/product-grid-optimized'

<ProductGrid
  viewMode="grid"
  searchQuery={searchQuery}
  category={category}
  showFavorites={showFavorites}
  priceRange={priceRange}
  sortBy={sortBy}
  onFavoritesCountChange={setFavoritesCount}
/>
```

### Виртуализированный каталог (для очень больших списков)
```tsx
import { VirtualizedProductGrid } from '@/components/catalog/virtualized-product-grid'

<VirtualizedProductGrid
  products={products}
  viewMode="grid"
  favorites={favorites}
  onToggleFavorite={toggleFavorite}
  isLoadingMore={isLoadingMore}
  hasMore={hasMore}
  onLoadMore={loadMore}
/>
```

## Хуки

### usePagination
Управляет пагинацией и автоматической подгрузкой:
```tsx
const pagination = usePagination({
  initialPageSize: 30,
  loadMoreSize: 10,
  threshold: 1000
})
```

### useProductsCache
Управляет кэшированием товаров:
```tsx
const cache = useProductsCache()
const cached = cache.get(cacheKey)
cache.set(cacheKey, products, total, hasMore)
```

## Производительность

### До оптимизации
- Загружались все товары сразу (до 5000+)
- Нет кэширования
- Медленный рендеринг больших списков
- Высокое потребление памяти

### После оптимизации
- Загружается только 30 товаров + подгрузка по 10
- Кэширование на 5 минут
- Виртуализация для больших списков
- Низкое потребление памяти
- Быстрый отклик интерфейса

## Настройки

### Размеры загрузки
```tsx
const pagination = usePagination({
  initialPageSize: 30,  // Начальная загрузка
  loadMoreSize: 10,     // Размер подгрузки
  threshold: 1000       // Расстояние до конца для автоподгрузки (px)
})
```

### Кэширование
```tsx
const CACHE_DURATION = 5 * 60 * 1000  // 5 минут
const MAX_CACHE_SIZE = 50             // 50 записей
```

### Виртуализация
```tsx
const ITEM_HEIGHT = 300      // Высота товара (px)
const CONTAINER_HEIGHT = 600 // Высота контейнера (px)
const OVERSCAN = 5           // Элементы за пределами видимой области
```

## Мониторинг

В консоли браузера можно отслеживать:
- `📦 Используем кэшированные данные` - данные загружены из кэша
- `🔄 Загружаем товары с параметрами` - новый запрос к API
- `✅ Ответ сервера` - данные получены с сервера
- `Показано: X из Y` - информация о загруженных товарах
